# SQL e Análise de Logs - Sprint 6

## 📖 Sobre o projeto

Este repositório reúne as atividades desenvolvidas durante o projeto da Sprint 6 da formação em **Quality Assurance** da **TripleTen**.

O objetivo foi utilizar consultas SQL para analisar um banco de dados de corridas de táxi e empregar comandos do terminal Linux para investigar arquivos de log, identificar erros e organizar registros para análise.

---

## 🎯 Atividades realizadas

### Análise de Logs

- Pesquisa de registros utilizando comandos Linux.
- Filtragem de logs por endereço IP.
- Identificação de erros HTTP.
- Organização de arquivos de log em diretórios.
- Separação de registros por código de erro.

### Banco de Dados

- Consultas SQL utilizando PostgreSQL.
- Contagem e agrupamento de registros.
- Utilização de JOIN entre tabelas.
- Aplicação de funções de agregação.
- Uso de GROUP BY, HAVING e ORDER BY.
- Utilização de CASE para classificação de dados.
