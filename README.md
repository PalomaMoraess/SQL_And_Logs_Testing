# SQL e Análise de Logs - Sprint 6

## 📖 Sobre o projeto

Este repositório reúne as atividades desenvolvidas durante o projeto da Sprint 6 da formação em **Quality Assurance** da **TripleTen**.

O projeto teve como objetivo investigar registros de log em ambiente Linux e realizar consultas SQL em um banco de dados de corridas de táxi, utilizando técnicas de análise de dados para identificar problemas e validar informações do sistema.

---

## 🎯 Atividades realizadas

### 💻 Análise de Logs (Linux)

- Pesquisa de registros utilizando comandos do terminal.
- Filtragem de logs por endereço IP.
- Identificação de erros HTTP.
- Organização de arquivos e diretórios.
- Separação de registros por código de erro.

### 🗄️ Banco de Dados (SQL)

- Consultas SQL em PostgreSQL.
- Contagem e agrupamento de registros.
- Utilização de JOIN entre tabelas.
- Uso de GROUP BY e HAVING.
- Ordenação com ORDER BY.
- Aplicação de CASE para classificação de condições climáticas.
- Análise de dados de corridas de táxi.
